# ClaimPack discovery

This repository carries machine-readable mirrors of two candidate claim
packages generated by
[`ipitchford/claimpack`](https://github.com/ipitchford/claimpack) at
`v0.1.0-candidate.1`:

- [`claimpacks/z20/`](claimpacks/z20/) describes the candidate determination
  \(z(20)=6\).
- [`claimpacks/vr2-k4/`](claimpacks/vr2-k4/) describes the companion candidate
  determination \(\mathrm{VR}_2(K_4)=20\).

Validate both packages with the validator pinned to the same ClaimPack
release:

```bash
uvx --from git+https://github.com/ipitchford/claimpack.git@v0.1.0-candidate.1 \
  claimpack validate claimpacks/z20
uvx --from git+https://github.com/ipitchford/claimpack.git@v0.1.0-candidate.1 \
  claimpack validate claimpacks/vr2-k4
```

## Release and assurance boundary

These mirrors are post-release discovery metadata. They are not part of the
bytes identified by tags `candidate-2026-07-26` or
`vr2-k4-v0.1-candidate`, or by either associated Zenodo version DOI. The
current-tree [`RELEASE_MANIFEST.sha256`](RELEASE_MANIFEST.sha256) advances to
bind this metadata while leaving those historical releases unchanged.

ClaimPack validation establishes structural integrity and internal identifier
consistency. It does not verify either mathematical claim, independently
reproduce a computation, provide peer review, establish novelty, or raise the
assurance status reported in the papers and AI indexes.
